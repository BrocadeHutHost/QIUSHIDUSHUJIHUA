# DGUT 求是读书计划-自动阅读助手UI改良

在东莞理工学院求是读书计划里自动计时 + 自动翻页，无需手动盯着屏幕翻书，就能完成每本书 4 小时的学分要求。全新UI带深色浅色切换，带给你更优雅的挂机体验。

通识教育活动学分查询：https://tsjy.dgut.edu.cn/pc/#/creditsSearch

### 它能做什么

- **自动翻页/切节/切书**：打开课件后自动翻页；书内的多个小节自动切换；一本书读满 4 小时后，自动换到下一本；启动脚本放后台即可。
- **持久化计时**：后台统计阅读时间，关掉浏览器再打开，能接着之前累计的时间继续。
- **平台时间同步**：定期和优学院平台对一次时间，确保统计的时长 = 服务端真实时长。
- **走神提醒自动关闭**：平台弹出的“你在看吗”确认框会自动帮你点掉。
- **全新 MD3 界面**：采用 Material Design 3 设计规范，支持浅色/深色/跟随系统主题切换，提供沉浸式 Hero 卡片计时器及水波纹交互反馈。
- **防遮挡折叠**：面板可一键折叠为迷你 FAB 悬浮窗，不遮挡阅读视线。

面板上的信息从上到下依次是：

| 显示内容 | 含义 |
| :--- | :--- |
| **状态圆点 + 标题** | 脉冲圆点代表正常运行中；灰色代表已暂停。右侧为主题切换与折叠按钮 |
| **计时数字** | 当前这本书已经阅读的累计时间 |
| **进度条 + 百分比** | 距离完成 4 小时学分要求的进度 |
| **书名 - 小节名** | 正在读的是哪本书、哪个小节 |
| **主按钮** | 点击可以暂停/继续自动阅读（运行时按钮会变为灰色 Tonal 样式） |
| **间隔设置** | 每隔多少秒翻一页（默认 30 秒，一般不用改） |
| **服务端时间** | 平台上记录的时间，点“同步”按钮可以手动对齐 |
### 常见问题

**问：为什么有时候面板上显示的时间和服务端不一样？**
服务端是平台记录的实际已读时长，更新有一定延迟；脚本会定期自动同步一次。短时间内的差异是正常的，也可以点击“同步”按钮立即对齐。

**问：翻页间隔设多少合适？**
默认 30 秒一页是比较合理的速度，不会太快也不会太慢。觉得不合适可以调，但建议不要短于 10 秒。

**问：如何切换深色模式？**
点击面板右上角的“太阳”图标，可以在浅色、深色、跟随系统三种模式间循环切换，设置会自动保存。
